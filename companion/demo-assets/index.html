A small library to try everything.

Fictional courses, real sync and retrieval. No NYU account needed. This site runs in the companion on your computer.

Try it in the extension

  1. Pair the Chrome extension using the code in the companion window.
  2. Open Browse resources → Advanced → Demo and testing and select Local demo.
  3. Select Demo 2026 Fall, then Sync semester.
  4. Browse nested modules, search “east gate,” and download a file. For cache controls, open Advanced and enable manual cache buttons.

For a connected AI client, ask: “Use the demo library to sync Demo 2026 Fall, retrieve the urban garden field guide, read its bytes, and tell me the observation code.” MCP tools must use provider: "demo" on each call.

Demo catalogs, encrypted caches and requests are separate from your NYU library. This demonstrates the extension workflow; it does not validate NYU authentication or institution-specific behavior.
