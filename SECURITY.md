# Security reports

Email **khinaungwrk@gmail.com** with the subject **Brightspace Context security report** for suspected vulnerabilities. Please report privately before opening a public issue containing exploit details.

Include affected versions, a short description and reproduction steps using synthetic data where possible. Do not send school passwords, browser cookies, pairing tokens, course documents or complete private logs. There is no guaranteed response time or paid vulnerability program.

This is a preview. The extension uses the user's existing NYU session; the companion uses a paired loopback connection and stores files locally without application-level encryption. Desktop MCP clients can receive requested data under their own processing policies. Account-switch isolation and some data-management controls remain unfinished. Read the [privacy policy](https://brightspace-context.khin101.chatgpt.site/) and use a single-account local setup while those boundaries are being completed.
