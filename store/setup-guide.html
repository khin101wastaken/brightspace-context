Set up Brightspace Context

Browse NYU Brightspace course resources and retrieve individual PDF, PowerPoint and Word files through your own computer.

1. Install the Chrome extension

Install from the Chrome Web Store

Open the listing in Chrome, choose Add to Chrome, and confirm the install. Sign into NYU Brightspace in that same Chrome profile to browse your courses.

To try sample courses with just the extension, open Resources → Advanced → Demo and testing → Hosted demo. Choose Open demo LMS, then return to Resources and sync Demo 2026 Fall.

2. Install the Windows companion for desktop AI

Run the installer, then open Brightspace Context Companion from the Start menu. Copy the pairing code from its popup into the Chrome extension. The companion runs in the taskbar tray. Right-click its icon to open the dashboard, show the code again, or enable Launch at sign-in.

For updates, choose Exit companion in the tray and stop its desktop MCP connection before running the newer installer. Reopen the companion and quit and reopen Codex afterward. Pairing and existing cache data are preserved.

3. Browse and sync your semester

Choose Browse resources, select a semester, and click Sync semester. Expand modules to browse their files and notes. Search highlights matching filenames and module text; download buttons save individual accessible files. Browsing and ordinary downloads can be used without the companion.

4. Connect Codex

  1. Right-click the companion tray icon and choose Open controls.
  2. Click Connect to Codex to register the local Brightspace MCP server.
  3. Quit and reopen Codex to load the connection. Keep Chrome and the companion running, with automatic retrieval enabled in the extension.

For another supported local MCP client or an existing custom configuration, open the installed Setup guide from the Start menu and copy its exact Command and Argument into a STDIO server named brightspace-context.

Try asking: “Find a reading from my synced courses, retrieve it, and read the actual file before answering.”

Try without an NYU account

With the companion running, choose Resources → Advanced → Demo and testing → Local demo and sync Demo 2026 Fall. The local demo LMS has fictional courses, original sample documents, and resync/session-expiry controls. Demo catalogs and cached files stay separate from NYU. In MCP use provider: "demo" on every demo call. Full review guide.

Browser pairing connects the extension to the companion. The desktop MCP connection is configured separately. The MCP server reads PDF text layers and Word or PowerPoint text in bounded pages with read_document_text. Original files remain available through MCP resources. Both paths read from the encrypted cache in memory.

For clients that require a local file, explicitly enable Settings → Temporary file exports in the extension and request export_document. Optional exports are unencrypted copies with a 15-minute expiration, removed on normal shutdown; a crash can leave them until the next companion start. Exports are off by default.

Version 0.9.2 encrypts persistent companion data using a Windows-account-protected key. Saved browser catalogs unlock through the companion after a browser restart. Newly synced unpaired catalogs last for that browser session only. The first updated start verifies encrypted copies before retiring recognized legacy plaintext files; preserve the original cache and Windows profile if migration cannot finish.

Troubleshooting and local storage

The companion uses short normal status lines with NYU/Demo labels, sync totals and cache results. Use the verbose-log shortcut below for full event IDs and request timings.

Companion unavailable: start the companion, then choose Check connection. Pairing needs refreshing: use Pair again and the current companion code. Sign-in required: sign into Brightspace in Chrome and retry the request.

Cached data normally lives in %USERPROFILE%\BrightspaceContext\cache. The cache is bounded to 500 MiB, with a 50 MiB per-file limit. Disconnecting the browser and uninstalling the companion preserve cached data. See the privacy policy for removal instructions.

Open Brightspace Context → Troubleshooting → Companion (verbose logs) from the Start menu for additional connection diagnostics. Avoid including course files or pairing credentials in support emails.
