1. Install and start the companion

Run the installer, then open Brightspace Context Companion from the Start menu. Node and the required dependencies are included. Keep the companion window open; it displays your browser pairing code.

For updates, close the companion and stop its desktop MCP connection before running the newer installer. Reopen the companion and restart MCP afterward. Pairing and existing cache data are preserved.

2. Add the Chrome extension

The extension has not yet been published in the Chrome Web Store. This preview uses Chrome’s manual installation flow.

  1. Open Brightspace Context → Setup guide from the Start menu. It shows the exact installed extension folder.
  2. In Chrome, open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the extension folder shown in the installed guide. If you already use the development copy, keep that copy and reload it instead of adding a second one.
  4. Sign into NYU Brightspace in the same Chrome profile. Open the extension and enter the code shown by the companion.

3. Browse and sync your semester

Choose Browse resources, select a semester, and click Sync semester. Expand modules to browse their files and notes. Search highlights matching filenames and module text; download buttons save individual accessible files. Browsing and ordinary downloads can be used without the companion.

4. Connect desktop ChatGPT / a supported local MCP client

  1. Open the installed Setup guide from the Start menu and locate Connect a desktop MCP client.
  2. In your desktop client’s MCP settings, add a local STDIO server named brightspace-context. Copy the exact Command and Argument from the installed guide. The guide also provides the equivalent JSON.
  3. Save, enable the server and restart its connection. Keep Chrome and the companion running, with automatic retrieval enabled in the extension.

Try asking: “Find a reading from my synced courses, retrieve it, and read the actual file before answering.”

Try without an NYU account

With companion 0.9.3 running, choose Settings → Local demo in the extension, then open Resources and sync Demo 2026 Fall. The local demo LMS has fictional courses, original sample documents, and resync/session-expiry controls. Demo catalogs and cached files stay separate from NYU. In MCP use provider: "demo" on every demo call. Full review guide.

Browser pairing connects the extension to the companion. The desktop MCP connection is configured separately. File reading depends on your client’s tools; normal retrieval returns original PDF, PPTX or DOCX bytes through MCP resources without creating a plaintext file path.

For clients that require a local file, explicitly enable Settings → Temporary file exports in the extension and request export_document. Optional exports are unencrypted copies with a 15-minute expiration, removed on normal shutdown; a crash can leave them until the next companion start. Exports are off by default.

Version 0.9.2 encrypts persistent companion data using a Windows-account-protected key. Saved browser catalogs unlock through the companion after a browser restart. Newly synced unpaired catalogs last for that browser session only. The first updated start verifies encrypted copies before retiring recognized legacy plaintext files; preserve the original cache and Windows profile if migration cannot finish.

Troubleshooting and local storage

Companion unavailable: start the companion, then choose Check connection. Pairing needs refreshing: use Pair again and the current companion code. Sign-in required: sign into Brightspace in Chrome and retry the request.

Cached data normally lives in %USERPROFILE%\BrightspaceContext\cache. The cache is bounded to 500 MiB, with a 50 MiB per-file limit. Disconnecting the browser and uninstalling the companion preserve cached data. See the privacy policy for removal instructions.

Open Brightspace Context → Troubleshooting → Companion (verbose logs) from the Start menu for additional connection diagnostics. Avoid including course files or pairing credentials in support emails.
