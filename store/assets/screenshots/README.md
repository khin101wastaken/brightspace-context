Each is labelled “Synthetic demonstration data.” They include no real catalog, documents, token or student information. The synthetic preview is development-only and is excluded from the upload ZIP.

- `02-search.jpg`: dark theme, an unfinished-word search, module-note and filename highlighting.
- `03-sync.jpg`: two completed segments out of five; the currently scanning course remains neutral.
- `04-popup.jpg`: the actual connected Chrome popup supplied by the publisher, placed proportionally in a 1280×800 HTML listing layout with explanatory text. The original pixels/content are not retouched. The original capture is preserved in `../popup-original.png`; the reproducible layout is `../popup-listing.html`. Only the semester label and course count are visible, with no course names, documents or credentials.

All four listing images are full-bleed 1280×800 RGB JPEGs. They illustrate the interface, not a claim that a reviewer has NYU access. The other sample course outlines intentionally show unavailable until synced. Upload the numbered JPEGs, not the original portrait PNG or HTML layout.
