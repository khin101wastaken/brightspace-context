Brightspace Context

Set up the companion on your Apple silicon Mac.

  1. Drag Brightspace Context to Applications. Open it from there and look for the document icon in the menu bar.
  2. Install the Chrome extension and sign into NYU Brightspace in the same Chrome profile.
  3. Choose Show pairing code from the menu bar and enter the code in the extension.
  4. Choose Open dashboard, click Connect to Codex, then quit and reopen Codex.
  5. Use Browse resources in Chrome to sync a semester, then ask Codex to find and read a course file.
Test the development extension

For features ahead of the Chrome Web Store release, use Load unpacked in chrome://extensions. Select Contents/Resources/app/extension inside the installed app bundle. To see that folder in Finder, Control-click Brightspace Context and choose Show Package Contents. Pair the development copy with the companion.

The companion runs in the menu bar. Choose Quit Brightspace Context to stop it. Your encrypted cache is in ~/Library/Application Support/Brightspace Context/cache.
