WINDOWS BETA · NYU · CHROME

Your courses, ready for context.

Node and the companion are included. You do not need to install developer tools or run shell commands.

Try the local demo

Keep the companion running and pair the extension. In Resources → Advanced → Demo and testing, choose Local demo and sync Demo 2026 Fall. Open the fictional demo LMS to try added readings and session expiry. Demo libraries stay separate from NYU. Connected MCP tools use provider: "demo".

1. Start the companion

Open Brightspace Context Companion from the Start menu. The pairing code appears above the taskbar, pauses briefly, then fades over ten seconds. Hover over the popup to keep it visible. Use the tray menu to show the code again, open the controls, enable Launch at sign-in, or exit.

2. Add the Chrome extension

  1. Open the Chrome Web Store listing in Chrome and choose Add to Chrome.
  2. Sign into NYU Brightspace in that Chrome profile.
  3. Open the extension, enter the code from the companion controls, and choose Connect.
Developer installation

For development, use Load unpacked at chrome://extensions with this installed folder:

app\extension (inside this installation)

Use one copy of the extension per Chrome profile.

3. Connect a desktop MCP client

In the companion controls, click Connect to Codex. Quit and reopen Codex to load the Brightspace connection. If you already configured Brightspace or use another desktop MCP client, use the manual settings below.

Add a STDIO server named brightspace-context. Use these absolute paths:

Command:

runtime\node.exe (inside this installation)

Argument:

app\mcp\start.js (inside this installation)

Equivalent JSON configuration:

Restart the MCP connection as required by your client. Use read_document_text to read existing PDF, DOCX and PPTX text in pages. Ask for a temporary download link if you want to open the original file.
If your client requires a local file, explicitly enable Settings → Temporary file exports in the extension, then request export_document. These optional copies are unencrypted, expire after 15 minutes, and are removed on normal companion shutdown. A crash can leave them until the companion starts again. Exports are disabled by default.


4. Check one reading
Open Resources in the extension, select a semester and click Sync semester. Then ask your connected chat to find one uncached course PDF, request it with request_document, wait for it to be ready, and read its contents. Keep Chrome signed in and the companion running.


Updates and uninstall
Choose Exit companion in the tray and stop its desktop MCP connection before installing an update. Keep the extension loaded from this installation's stable folder; reload it in Chrome after updating and restart MCP. The first updated companion start migrates recognized legacy files to encrypted storage and verifies the copies before retiring plaintext originals. Use Windows Installed apps → Brightspace Context → Uninstall to remove the application and shortcuts.
Uninstall preserves the encrypted cache, pairing and Windows-protected key in %USERPROFILE%\BrightspaceContext\cache. Keep these files and the original Windows profile for recovery. Remove the extension and desktop MCP entry separately. To erase local companion data, stop the companion and explicitly remove the cache directory. Ordinary Downloads are separate and remain where you saved them.
Protected storage
Persistent companion data is encrypted with a key protected by your Windows account. Saved browser catalogs are encrypted too; after a browser restart, start the companion to unlock them without entering another pairing code. Without pairing, newly synced browser catalogs last only for that browser session. If an older cache cannot be migrated or unlocked, preserve it and resolve the reported problem; do not reset or replace its key.


Troubleshooting
The tray controls show browser connection, the file queue, and cached files. Use them to cancel queued requests or clear cached originals. For timestamped diagnostics, exit the tray companion and open Brightspace Context → Troubleshooting → Companion (verbose logs) from the Start menu. Verbose mode adds local request status codes and timings. Keep only one companion instance running.


This is an unsigned Windows x64 beta. Automatic updates and Mac/Linux packages are future steps. HTML downloads save the document itself; their linked assets are not packaged.
